# Multi-Screen Calculator
## Project Overview
A simple Android calculator app developed using Kotlin and XML for the Veda Technology Android Development Track (Day 13). It performs basic arithmetic and displays the calculation history on a separate screen.
## Technologies Used
- Kotlin
- XML Layouts
- Android Studio
## Features
- Two input fields for numbers
- Buttons for +, -, *, /
- Displays result dynamically
- Handles division by zero
- History screen displaying past calculations
## How to Run
1. Clone the repository. 2. Open in Android Studio. 3. Sync Gradle. 4. Run the app.
## Outcome
The application successfully performs arithmetic operations and transfers the calculation history to a second screen using Intent extras.
